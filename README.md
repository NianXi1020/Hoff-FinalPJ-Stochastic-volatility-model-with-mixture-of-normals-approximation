# Stochastic Volatility Notebook Demo

This repository contains a lightweight Jupyter Notebook and helper modules for
running a stochastic volatility (SV) model with a normal-mixture observation
approximation. The notebook is designed to process large CSV datasets located in
a folder named `2005年__20250905` placed next to the notebook.

Key files:

- `notebooks/sv_mixture_demo.ipynb`: guided workflow with Chinese comments and
  English print statements/plot labels.
- `sv_toolkit/`: helper modules for data loading, MCMC sampling, and plotting.
- `figures/`: output directory for PNG charts generated by the notebook.

Run the notebook inside Jupyter, adjust the data directory and sampling
parameters, and start with small subsets of the data (e.g., a single file or a
few thousand rows) to keep runtime manageable.
